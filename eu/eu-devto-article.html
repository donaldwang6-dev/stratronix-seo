💻 Quick Start: Deploy in 5 Minutes

Step 1: Install OpenClaw

$ pip install openclaw
$ openclaw --version
OpenClaw v1.2.0 (Apache-2.0)

Step 2: Connect to STRATRONIX PAA

$ openclaw connect --host sta-100.local

🚀 Connecting to STRATRONIX STA-100...
✅ Hardware detected: STA-100 (8-core ARM, 16GB DDR4, 512GB NVMe)
✅ OpenClaw framework v1.2.0 loaded
✅ 4 AI agents initialized: Planner, Retriever, Executor, Verifier
✅ Local knowledge base: 487 GB available

Step 3: Configure 4-Agent Workflow

# openclaw.yaml
agents:
  planner:
    model: claude-3.5-sonnet
    role: "Decompose complex tasks"
  retriever:
    model: bge-large-zh
    role: "Semantic search local KB"
    vector_db: faiss
  executor:
    model: claude-3.5-sonnet
    role: "Run code, APIs, file ops"
  verifier:
    model: claude-3.5-sonnet
    role: "Validate outputs"

Step 4: Run Your First Agent Task

from openclaw import Client

client = Client(host="sta-100.local", port=8080)

result = client.agents.run(
    task="Analyze this CSV of customer data and identify top 3 churn risks",
    agents=["planner", "retriever", "executor", "verifier"]
)

print(result.summary)
# 'Identified 3 churn risks: John Doe (87%), Jane Smith (76%), Bob Johnson (71%)'
