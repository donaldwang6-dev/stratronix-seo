Five Core Selling Points

🎯 1. One-Click Deployment — OpenClaw "One-Click Launch"

Designed for OpenClaw's one-click launch. XFCE GUI lets non-technical users deploy first local automation in under 5 minutes.

🔒 2. Privacy-First — All Data Local

API credentials, task logs, RAG indexes, SOP workflows all stored in local eMMC + MicroSD. Never leave the device.

⚡ 3. Inference Local — OpenClaw AutoAgent

All agent orchestration, tool calling, automation decisions execute on local ARM Cortex SoC. Inference does not depend on cloud.

🌐 4. Hybrid Connectivity — Wi-Fi + Gigabit Ethernet

Dual-band 5GHz / 2.4GHz Wi-Fi: Flexible deployment.
RJ45 Gigabit Ethernet: Mission-critical stability.
Note: Network connectivity is only used for system updates and clock sync. Inference and data stay local.

📺 5. HDMI Patent Output — Big-Screen Visualization

STA-100 has received HDMI licensing body patent authorization, allowing real-time local agent status projection on big screens.
