Product Positioning

STA-100 is the first PAA 1.0 reference implementation of STRATRONIX PAA (Personal AI Appliance) standard. It is a desktop ARM Edge AI Agent Gateway, not a rack server.

One-line positioning: Keep the data. Outsource the thinking.

STA-100 is driven by OpenClaw (BSD-3-Clause open source) + AutoAgent plug-and-play engine. It calls DeepSeek / Gemini / Claude / ChatGPT cloud LLM APIs as the "brain", while keeping credentials / logs / SOPs / RAG indexes always local.

Five Core Selling Points

🎯 1. One-Click Deployment — OpenClaw "One-Click Launch"

Designed for OpenClaw's one-click launch feature. Users don't need complex CLI. XFCE GUI lets non-technical users deploy first automation in under 5 minutes.

🔒 2. Privacy-First Architecture — Local Data Processing

API credentials, task logs, RAG indexes, SOP workflows all stored in local eMMC + MicroSD. Never leave the device — even when calling cloud LLM APIs, only the "question" goes out. The "answer + history" stays local.

🌐 3. Hybrid Connectivity — Wi-Fi + Gigabit Ethernet Dual-Link

Dual-band 5GHz / 2.4GHz Wi-Fi: Flexible deployment.
RJ45 Gigabit Ethernet: Mission-critical stability (finance / medical / legal).

⚡ 4. Edge Intelligence — 24×7 Online Gateway

STA-100 is not a "use-and-close" device. It's designed as a 24/7 always-on edge gateway: RPA / IoT device management / web monitoring / edge preprocessing.

📺 5. HDMI Patent Output — Big-Screen Visualization

STA-100 has received HDMI licensing body patent authorization, allowing real-time AI Agent state projection on big screens via HDMI: SMB "digital worker" dashboards / factory IoT gateway monitoring / living room smart assistant screens.

Four Application Scenarios

📚 1. Private AI Agents — Personal RAG + Private Assistant

Index personal documents / notes / emails / chats into local MicroSD. Use OpenClaw AutoAgent to call DeepSeek / Gemini / Claude / ChatGPT. Knowledge base always local.

⚙️ 2. Workflow Automation — Automated Web Tasks

Automate repetitive web tasks: SaaS management (CRM / ERP / support batch ops) · data entry (multi-platform aggregation) · social media monitoring (multi-account auto-reply / content scraping).

🏢 3. Industry-Specific Solutions — ERP / Retail / IoT

  • Lightweight ERP Automation: SMB manufacturing / retail ERP workflows
  • Smart Retail Assistant: POS / inventory / customer management
  • Secure Industrial IoT Gateway: Factory floor data collection + edge preprocessing

📡 4. Edge Computing — Real-Time Processing

Real-time data processing at the network edge, reducing latency and cloud costs.
