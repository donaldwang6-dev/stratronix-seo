Overview

The PAA fault tree is the standardised classification used by STRATRONIX support engineers, the built-in watchdog, and the on-device AI assistant. Each fault has a unique code (FT-XX-YY), a severity tier, a self-healing indicator, and a resolution path.

Why a fault tree? Two reasons:

  1. Faster triage: IT administrators and on-device AI can identify a fault by its symptoms and resolve without waiting for human support.
  2. Lower support cost: Self-healing and standardised fixes reduce the lifetime cost per unit, supporting our $399 USD price point with 2-year warranty.
📌 Severity definitions: CRIT Service down — 1h response SLA · HIGH Degraded performance — 4h SLA · MED Single feature failure — 1 business day · LOW Cosmetic / informational — next release

How to use this fault tree

For IT administrators

  1. Run paa-status — note which subsystem shows RED
  2. Find the subsystem in this fault tree (Categories 1-5)
  3. Identify the specific fault code (e.g. FT-11-04)
  4. Apply the listed resolution; verify with paa-status again
  5. If unresolved, contact support@stratronix.ai with the fault code

For the on-device AI assistant

The PAA AI assistant has the entire fault tree embedded and can guide a non-technical user through diagnosis and resolution conversationally. Example:

User: "AI is slow today."

PAA AI: "Let me check your LLM service. Looking at FT-31-01, your token rate is 40% below baseline. This could be thermal throttling (FT-31-04). Current CPU temperature: 82°C. I'd recommend checking that the PAA's ventilation openings are unobstructed. Want me to walk you through it?"

For STRATRONIX support engineers

All support tickets are auto-tagged with the most likely fault code based on the paa-diagnostics bundle. This shrinks mean-time-to-resolution by an estimated 60%.
