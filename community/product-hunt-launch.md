**Hardware (STA-100):**
- ARM multi-core + integrated NPU
- 16GB / 32GB RAM
- 512GB / 1TB / 2TB NVMe SSD
- 2.5GbE + Wi-Fi 6
- 30W idle power
- 2-year warranty
- CE / FCC / RoHS

**Software:**
- OpenClaw AI Agent OS (open source, Linux-based)
- AutoAgent multi-agent orchestration
- PAA SDK (Python, Node.js, Go)
- 89 language packs pre-installed
