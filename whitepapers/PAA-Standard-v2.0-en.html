1. PAA (Personal AI Appliance) Definition

PAA (Personal AI Appliance) is the Edge AI Agent Gateway product category proposed by STRATRONIX in 2026:

  • Desktop ARM box (NOT 1U-4U rack server)
  • OpenClaw (BSD-3-Clause) open-source browser automation & agent orchestration platform
  • AutoAgent plug-and-play automation engine
  • All data and inference stay local (core principle)
  • Credentials / logs / SOPs / RAG indexes / inference execution always on local ARM Cortex SoC
  • 24×7 online edge gateway (Wi-Fi + Gigabit Ethernet only for system updates and clock sync)

One-line positioning: Keep the data. Outsource the thinking.
