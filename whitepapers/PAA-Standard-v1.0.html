1. Executive Summary

This document formally proposes PAA (Private AI-Agent Appliance) as a new product category for the AI hardware industry. PAA is defined as a self-contained hardware appliance that:

  1. Runs a frontier-parameter LLM (≥ 30B, target 70B) entirely cloud-based
  2. Exposes no outbound network calls in inference mode
  3. Ships with pre-built vertical agents for enterprise workflows
  4. Complies by-design with EU AI Act 2026 (Regulation 2024/1689), GDPR, HIPAA-equivalent, and China's Generative AI Interim Measures (生成式人工智能服务管理暂行办法)

PAA is to cloud AI what the on-prem server was to the public cloud — a category built for enterprises that need privacy by design, data sovereignty, and predictable cost.

3. Why PAA Matters

The cloud AI market is dominated by 3 hyperscalers (Microsoft Azure OpenAI, Google Vertex AI, AWS Bedrock). An enterprise needing "use AI on internal data" today faces 3 choices:

  1. Send data to a public cloud → violates GDPR / China's Data Security Law / industry compliance
  2. Self-host open-source LLMs on commodity GPUs → operationally complex, no vertical agents, no compliance
  3. PAA — appliance-style, turnkey, compliance-by-design

PAA is the third option. It captures enterprises that cannot choose options 1 or 2 due to regulatory or strategic reasons.

4. Compliance-as-a-Feature

PAA's defining property is compliance by design, not compliance by configuration.

  • EU AI Act 2026: PAA achieves "Limited Risk" classification by default (no biometric processing, no subliminal manipulation, no social scoring) and supports "High Risk" classification through configuration (human-in-the-loop mandatory).
  • GDPR Article 22: PAA does not produce solely-automated decisions affecting data subjects without human-in-the-loop. Built-in audit trail provides "right to explanation" (Article 22(3)).
  • China Generative AI Interim Measures: STA-100 ships preconfigured with content moderation aligned with China's baseline requirements (Article 4) and supports Algorithmic Filing (算法备案) export.

5. Open Ecosystem

PAA is open at every layer below the appliance:

  • OpenClaw OS (BSD-3-Clause): inference runtime, agent framework, compliance audit log
  • STRATRONIX SDK (Apache-2.0): Python SDK for building custom agents
  • Agent Marketplace: free agents from STRATRONIX; paid agents from partners

Only the appliance hardware and the curated agent bundle are proprietary. Everything else is open source.
