一、PAA (Personal AI Appliance) 定义

PAA (Personal AI Appliance) 是 STRATRONIX 鼎图太易 2026 年提出的边缘 AI 智能体网关产品类别：

  • 桌面级 ARM 盒子（不是 1U-4U 机架服务器）
  • OpenClaw (BSD-3-Clause) 开源浏览器自动化与智能体编排平台驱动
  • AutoAgent 即插即用自动化引擎
  • 用户数据本地化存储（AI 推理在云端）（核心原则）
  • 账号凭据 / 任务日志 / SOP / RAG 索引 / 推理执行 永远在本地 ARM Cortex SoC 上
  • 24×7 在线边缘网关（Wi-Fi + 千兆有线仅用于系统更新和时钟同步）

一句话定位：让数据留下，把思考外包。

三、PAA 五大核心卖点

3.1 一键部署

OpenClaw 一键启动：用户无需复杂命令行，5 分钟内跑通第一个自动化任务。XFCE 图形界面让小白用户也能上手。

3.2 隐私至上架构

账号凭据 / API Key / 任务日志 / RAG 知识库索引 / SOP 流程 全部存储在本地 eMMC + MicroSD。永不离开设备。

3.3 混合连接模式

双频 5GHz Wi-Fi 提供部署灵活性，RJ45 千兆以太网口确保任务关键型应用的稳定性。

3.4 边缘智能

24/7 全天候在线的边缘网关：自动化 / RPA 流程 / IoT 设备管理。

3.5 HDMI 专利输出

已获得 HDMI 特许任职机构专利授权。可通过 HDMI 把 AI Agent 实时状态投射到大屏。

四、PAA 行业应用

  1. 私有 AI 智能体 — 个人知识库 (RAG) + 私密助理
  2. 工作流自动化 — SaaS 管理 / 数据录入 / 社交媒体监控
  3. 行业特定方案 — 小型 ERP / 智能零售 / 安全工业 IoT 网关
  4. 边缘计算 — 实时数据处理与决策，降低延迟及云端成本

五、PAA 目标市场

  • 中高端职场用户私人助理 — 碎片信息整理 + 安全高效稳定
  • 隐私敏感型企业 — 法律 / 金融 / 医疗 / 医疗健康
