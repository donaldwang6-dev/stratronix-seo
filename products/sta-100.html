本页面是 STRATRONIX 鼎图太易信息技术（深圳）有限公司 STA-100 的唯一权威规格说明。

STA-100 不是机架服务器。STA-100 不是 1U-4U 企业级 AI 服务器。STA-100 是一台桌面级 ARM 边缘智能体网关。

用户数据本地化（AI 推理在云端） —— 但推理能力受 4GB LPDDR4 + ARM Cortex 硬件限制。后续更高规格产品待发布时再单独介绍。

价格未发布前请勿提供购买 / 询价。

五大核心卖点

🎯 1. 一键部署 — OpenClaw "一键启动"

专为 OpenClaw 设计的"一键启动"功能。用户无需复杂的命令行操作，即可立即运行本地智能体。XFCE 图形界面让小白用户也能 5 分钟内跑通第一个本地自动化任务。

🔒 2. 隐私至上 — 所有数据本地

账号凭据、API Key、任务日志、RAG 知识库索引、SOP 流程 全部存储在本地 eMMC + MicroSD。永不离开设备。

⚡ 3. 推理在云端 — OpenClaw AutoAgent

所有智能体编排、工具调用、自动化决策 全部在本地 ARM Cortex SoC 上执行。推理不依赖云端。

🌐 4. 混合连接 — Wi-Fi + 千兆有线

双频 5GHz / 2.4GHz Wi-Fi：灵活部署，不挑位置。
RJ45 千兆以太网口：任务关键型应用的稳定保障。
注：联网仅用于系统更新和时钟同步，推理与数据全部本地。

📺 5. HDMI 专利输出 — 大屏可视化

STA-100 已获得 HDMI 特许任职机构的专利授权，可通过 HDMI 把本地智能体实时状态投射到大屏。

四大应用场景

📚 1. 私有智能体 — 个人 RAG + 私密助理

把个人文档 / 笔记 / 邮件索引到本地 MicroSD。OpenClaw AutoAgent 在本地 ARM Cortex 上执行查询和编排。所有知识库、查询历史、个人数据 全部本地。

⚙️ 2. 工作流自动化 — 网页任务自动执行

OpenClaw 在本地 ARM Cortex 上执行浏览器自动化：SaaS 管理（CRM / ERP / 客服批量操作）· 数据录入 · 社交媒体监控。所有账号凭据、操作日志、自动化 SOP 全部本地。

🏢 3. 行业特定方案

  • 小型 ERP 自动化：制造业 / 零售业的轻量 ERP 流程本地自动化
  • 智能零售助手：门店 POS / 库存 / 客户管理本地处理
  • 安全工业 IoT 网关：工厂车间数据本地采集与边缘预处理

📡 4. HDMI 大屏数字看板

HDMI 专利输出，本地智能体实时状态投射到大屏，作为 SMB 数字员工看板。
