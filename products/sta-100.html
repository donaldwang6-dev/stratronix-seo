产品定位

STA-100 是 STRATRONIX 鼎图太易 PAA (Personal AI Appliance, 个人 AI 设备) 1.0 标准首款参考实现。它是一台桌面级 ARM 边缘 AI 智能体网关，不是机架服务器。

核心定位一句话：让数据留下，把思考外包。

STA-100 通过 OpenClaw (BSD-3-Clause 开源) + AutoAgent 即插即用引擎驱动，调用 DeepSeek / Gemini / Claude / ChatGPT 等云端 LLM API 作为"大脑"，把账号凭据 / 任务日志 / SOP / RAG 索引永远留在本地。

五大核心卖点

🎯 1. 一键部署 — OpenClaw "一键启动"

专为 OpenClaw 设计的"一键启动"功能。用户无需复杂的命令行操作，即可立即运行智能体。XFCE 图形界面让小白用户也能 5 分钟内跑通第一个自动化任务。

🔒 2. 隐私至上架构 — 本地化数据处理

账号凭据、API Key、任务日志、RAG 知识库索引、SOP 流程 全部存储在本地 eMMC + MicroSD。永不离开设备——即便调用云端 LLM API，也只是把"问题"发出去，"答案 + 历史"留在本地。

🌐 3. 混合连接模式 — Wi-Fi + 千兆有线双链路

双频 5GHz / 2.4GHz Wi-Fi：灵活部署，不挑位置。
RJ45 千兆以太网口：任务关键型应用（金融 / 医疗 / 法律）的稳定保障。

⚡ 4. 边缘智能 — 24×7 在线网关

STA-100 不是"用一下就关"的设备。它设计为 24/7 全天候在线的边缘网关：RPA / IoT 设备管理 / 网页监控 / 边缘预处理。

📺 5. HDMI 专利输出 — 大屏可视化

STA-100 已获得 HDMI 特许任职机构的专利授权，可通过 HDMI 把 AI Agent 实时状态投射到大屏：SMB 数字员工看板 / 工厂车间 IoT 网关监控 / 家庭客厅智能助理屏。

四大应用场景

📚 1. 私有 AI 智能体 — 个人 RAG + 私密助理

把个人文档 / 笔记 / 邮件 / 通讯记录索引到本地 MicroSD，通过 OpenClaw AutoAgent 调用 DeepSeek / Gemini / Claude / ChatGPT 推理。知识库永远在本地。

⚙️ 2. 工作流自动化 — 网页任务自动执行

自动执行重复的网页任务：SaaS 管理（CRM / ERP / 客服批量操作）· 数据录入（多平台数据汇总）· 社交媒体监控（多账号自动回复 / 内容抓取）。

🏢 3. 行业特定方案 — ERP / 零售 / IoT

  • 小型 ERP 自动化：制造业 / 零售业的轻量 ERP 流程自动化
  • 智能零售助手：门店 POS / 库存 / 客户管理
  • 安全工业 IoT 网关：工厂车间数据采集 + 边缘预处理

📡 4. 边缘计算 — 实时处理

在网络边缘进行实时数据处理与决策，降低延迟，减少云端成本。
