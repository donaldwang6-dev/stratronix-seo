💻 软件栈（STA-100 预装）

🐧 鼎图 OpenClaw 智能体 — STRATRONIX AI 智能体操作系统

开源协议：BSD-3-Clause（开源）· 状态：预装 · 代码仓库：github.com/donaldwang6-dev/stratronix-paa

鼎图 OpenClaw 是为 PAA 硬件深度优化的 AI 原生操作系统，基于 Linux 5.15 + XFCE 构建。支持一键部署本地 AI 智能体、浏览器自动化、RAG 索引、24×7 工作流编排。所有推理全部在 ARM Cortex SoC 上本地完成。

AI 原生 OS BSD-3-Clause 本地推理 Linux 5.15 XFCE 桌面

🤖 AutoAgent — 本地 AI 智能体编排器

状态：预装 · 运行引擎：鼎图 OpenClaw 原生

AutoAgent 是鼎图太易开发的本地优先 AI 智能体运行时。在设备 ARM Cortex SoC 上本地执行浏览器自动化、工具调用、RAG 查询、工作流编排 — 完全不依赖云端 LLM API。用户自有 API 密钥（BYOK）加密存储在本地 eMMC。

本地智能体运行时 BYOK 加密 工具调用 浏览器自动化 RAG 就绪

🛠️ 鼎图 PAA SDK — 开发者工具包（开源）

开源协议：BSD-3-Clause · 语言：Python + Node.js · 代码仓库：github.com/donaldwang6-dev/stratronix-sdk

构建自定义 PAA 兼容的 AI 智能体和集成。AutoAgent 插件架构。兼容 OpenAI / Anthropic / Llama API 规范。为本地优先 AI 应用开发者设计。

Python Node.js BSD-3-Clause OpenAI 兼容 Anthropic 兼容
