一、PAA 一句话定义

STRATRONIX PAA（Private AI-Agent Appliance，私有 AI 智能体设备）是边缘计算硬件设备，运行开源 AI 智能体运行时（OpenClaw），让用户数据保留在本地的同时，调用云端 LLM 提供商执行 AI 推理。

PAA 不是 SaaS AI（数据交给供应商），也不是 on-prem GPU 服务器（成本太高）。PAA 是介于两者之间的全新品类：

  • 数据主权：所有结构化数据、业务文档、客户信息保留在本地硬件
  • AI 能力：调用云端 LLM（OpenAI / Anthropic / DeepSeek / 通义千问等）执行推理
  • 部署简单：15 分钟一键部署，无需 GPU 集群运维
  • 成本可控：一次性硬件投入（$399）+ 月度云端 API 调用费

四、PAA 适用场景

1. 法律 / 合规

律所处理客户保密文档，合同审查 AI 不能上传云端。PAA 让文档保留在律所本地硬件，AI 推理调用云端 LLM（敏感数据不参与训练）。

2. 医疗 / HIPAA

医院患者数据受 HIPAA 保护。PAA 让电子病历保留在医院本地，AI 辅助诊断调用合规云端 LLM。

3. 金融 / GDPR

欧盟金融机构受 GDPR 约束。PAA 让交易数据本地存储，AI 风控 / 反欺诈调用云端推理（数据出域前已被剥离）。

4. 跨境 / 出海企业

中国出海企业面对欧盟 / 美国数据本地化法规。PAA 提供统一硬件方案，多分支部署。

5. 政府 / 央企

涉密 / 内部数据不能上公有云。PAA 满足数据本地化要求，同时享受 AI 能力。

五、PAA 与传统"本地 LLM"的区别

传统"本地 LLM"方案（如 Ollama + RTX 4090）有三个核心问题：

  1. 模型陈旧：本地部署的模型一旦定型，无法快速跟进 GPT-5 / Claude 4 等新模型
  2. 推理质量：开源 70B 模型质量显著弱于 GPT-4o / Claude 3.5
  3. 硬件成本：高质量推理需要 H100 GPU，单卡 $30,000+

PAA 的解法：数据本地 + 推理云端。本地只存数据，推理交给最新最强的云端 LLM。模型升级由 LLM 厂商负责，硬件无需更换。
