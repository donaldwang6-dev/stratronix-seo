三、安装 OpenClaw

# 安装 OpenClaw
$ pip install openclaw

# 验证安装
$ openclaw --version
OpenClaw v1.2.0 (Apache-2.0)

四、初始化 4 Agent 配置

# 创建 openclaw.yaml
$ cat > openclaw.yaml << EOF
agents:
  planner:
    model: claude-3.5-sonnet
    role: "任务规划"
    tools: [plan_decompose, priority_estimate]
  retriever:
    model: bge-large-zh
    role: "知识检索"
    vector_db: faiss
    storage: ./knowledge
  executor:
    model: claude-3.5-sonnet
    role: "任务执行"
    tools: [code_executor, shell_executor]
  verifier:
    model: claude-3.5-sonnet
    role: "结果验证"
    tools: [fact_checker, logic_checker]

coordinator:
  type: "round_robin"
  max_iterations: 10
EOF

五、部署到 STA-100 硬件

# SSH 到 STA-100
$ ssh root@sta-100.local

# 检查硬件状态
$ openclaw detect
[OK] CPU: 8 核 ARM @ 2.4GHz
[OK] RAM: 16GB DDR4 (已用 1.2GB)
[OK] Storage: 512GB NVMe (已用 23GB)
[OK] Network: 1Gbps

# 部署 OpenClaw
$ openclaw deploy --target stratronix-sta-100

六、调用 OpenClaw API

# 通过 HTTP API 调用
$ curl -X POST http://sta-100.local:8080/api/v1/agent/run \
    -H "Content-Type: application/json" \
    -d '{
        "agent": "planner",
        "task": "分析本月销售数据并生成报告",
        "context": "本月销售额 230 万"
    }'

# 返回 JSON
{
    "status": "success",
    "agent_used": ["planner", "retriever", "executor", "verifier"],
    "result": "📊 已生成销售报告...",
    "iterations": 3,
    "time_ms": 1250
}

七、Python SDK 集成

from openclaw import Client

# 连接到本地 STA-100
client = Client(host="sta-100.local", port=8080)

# 调用 4 Agent 协同
result = client.agents.run(
    task="帮我写一份深圳 AI 公司市场推广方案",
    agents=["planner", "retriever", "executor", "verifier"],
    max_iterations=5
)

print(result.summary)
# '已生成深圳 AI 公司市场推广方案（基于内部知识库）'
