《什么是 PAA？— STRATRONIX 鼎图太易真实规格说明》

汪总 2026-07-25 13:41 LOCKED 之前的 PAA 文章规格定义错误（1U 机架 / 70B 本地模型 / AMD EPYC 等都不属实）。 本文根据 STRATRONIX 鼎图太易 STA-100 当前实际规格 重新定义 PAA。

一、PAA 的真实定义：边缘 AI 智能体网关

PAA (Personal AI Appliance，私人 AI 设备) 是 STRATRONIX 鼎图太易 (Shenzhen) 在 2026 年面向中高端职场用户 + 隐私敏感型企业 + SMB + 开发者社区推出的 边缘 AI 智能体网关。

PAA 不是大型 1U-4U 机架式服务器，也不是 on-premise 本地大模型推理机。它是一台放在桌面上 / 弱电箱 / 边缘节点的小型 ARM 盒子，核心职责是：

  1. 承载 OpenClaw + AutoAgent — 让用户 一键启动 浏览器自动化与智能体编排平台
  2. 混合连接云端 LLM — 把 DeepSeek / Gemini / Claude / ChatGPT 的 API 作为"大脑"，把账号凭据、任务日志、自动化 SOP 永远留在本地
  3. 24×7 边缘网关 — 双频 Wi-Fi + 千兆有线，承担 RPA / IoT / 边缘计算

核心定位（一句话）：

PAA 是 OpenClaw 智能体编排的"本地大脑"——云端 LLM 只负责思考，本地永远负责记忆和执行。

二、STA-100 当前真实硬件规格

模块 规格
处理器 (SoC) 八核 ARM Cortex 架构，高性能能效比
系统内存 4GB LPDDR4 RAM
内部存储 32GB eMMC (高速闪存)
扩展存储 MicroSD (TF卡) 插槽，最高 512GB；默认 64GB 出厂配置
网络连接 双频 5GHz / 2.4GHz Wi-Fi + RJ45 千兆以太网口
外部接口 USB 3.0 / 2.0，HDMI 输出，直流电源输入 (12V/2A)
专利 已获得 HDMI 特许任职机构的专利授权

三、PAA 软件与 AI 生态

模块 说明
操作系统 深度优化的 Linux 系统 (内核版本 5.15, XFCE 图形界面)
核心框架 OpenClaw：开源浏览器自动化与智能体编排平台 (BSD-3-Clause)
自动化引擎 AutoAgent：即插即用的自动化任务执行环境
LLM API 兼容 DeepSeek (R1/V3 优化) / Gemini / Claude / ChatGPT
数据存储 本地 SOP + 任务日志 + 账号凭据，永不离开设备

重要说明：PAA 不是 on-premise LLM，不内置 70B / 175B 大模型本地推理。 大模型推理发生在云端 API，PAA 负责：

  • ✅ 把 API 凭据保存在本地 (4GB eMMC + MicroSD)
  • ✅ 把自动化 SOP / 任务日志保存在本地
  • ✅ 把 RAG 知识库索引保存在本地
  • ✅ 让浏览器自动化 / RPA 流程在本地 24×7 执行
  • ✅ 通过 HDMI 把 AI Agent 状态可视化到大屏

四、PAA 五大核心卖点

1. 一键部署 — OpenClaw "一键启动"

专为 OpenClaw 设计的 一键启动 功能，用户无需复杂的命令行操作，即可立即运行智能体。XFCE 图形界面让小白用户也能 5 分钟内跑通第一个自动化任务。

2. 隐私至上架构 — 本地化数据处理与 SOP 存储

您的 账号凭据、API Key、任务日志、RAG 知识库索引、SOP 流程，全部存储在本地 eMMC + MicroSD。 永不离开设备——即便调用 DeepSeek / Gemini / Claude / ChatGPT API，也只是把"问题"发出去，"答案 + 历史"留在本地。

3. 混合连接模式 — 5G Wi-Fi + 千兆有线双链路

  • 双频 5GHz / 2.4GHz Wi-Fi：灵活部署，不挑位置
  • RJ45 千兆以太网口：任务关键型应用（金融 / 医疗 / 法律）的稳定保障

4. 边缘智能 — 24×7 边缘网关

PAA 不是"用一下就关"的设备。它设计为 24/7 全天候在线的边缘网关：

  • 处理自动化流程 (RPA)
  • 处理 IoT 设备管理
  • 处理网页监控 / SaaS 数据录入
  • 处理边缘 AI 推理预处理

5. HDMI 专利输出 — 大屏可视化

PAA 已获得 HDMI 特许任职机构的专利授权，可通过 HDMI 把 AI Agent 实时状态投射到大屏： - 中小企业门店的"数字员工"看板 - 工厂车间的 IoT 网关监控 - 家庭客厅的智能助理屏

五、PAA 行业应用

1. 私有 AI 智能体 — 个人知识库 (RAG) + 私密助理

把个人文档 / 笔记 / 邮件 / 通讯记录索引到本地 MicroSD，通过 OpenClaw AutoAgent 调用 DeepSeek / Gemini / Claude / ChatGPT 推理，知识库永远在本地。

2. 工作流自动化 — 网页任务自动执行

自动执行重复的网页任务： - SaaS 管理（CRM / ERP / 客服后台批量操作） - 数据录入（多平台数据汇总） - 社交媒体监控（多账号自动回复 / 内容抓取）

3. 行业特定方案

  • 小型 ERP 自动化：制造业 / 零售业的轻量 ERP 流程自动化
  • 智能零售助手：门店 POS / 库存 / 客户管理
  • 安全工业 IoT 网关：工厂车间数据采集 + 边缘预处理

4. 边缘计算 — 实时数据处理与决策

在网络边缘进行实时数据处理与决策，降低延迟，减少云端成本。
