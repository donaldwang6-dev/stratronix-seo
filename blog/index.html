一、PAA 的核心定义：私有智能体设备

PAA (Personal AI Appliance，私有智能体设备) 是 STRATRONIX 鼎图太易 2026 年推出的产品类别。

PAA 的核心，是私有智能体设备。

用户数据本地化存储（AI 推理在云端） —— 这是 PAA 与市场上几乎所有"AI 设备"的最关键区别。

PAA 三大核心原则

原则 说明
数据本地 账号凭据、API Key、任务日志、RAG 知识库索引、SOP 流程、个人笔记、客户档案 —— 全部存储在本地存储介质，永不离开设备
推理在云端 OpenClaw AutoAgent 编排、工具调用、自动化决策 —— 全部在本地 ARM Cortex SoC 上执行
设备私有 用户拥有物理硬件所有权，软件开源（OpenClaw BSD-3-Clause），不依赖任何云服务持续运营

所有这些组件全部在本地 ARM Cortex SoC 上运行，不依赖任何云服务持续运营。

四、PAA 五大核心卖点

1. 数据本地存储

账号凭据、API Key、任务日志、RAG 知识库索引、SOP 流程 全部存储在本地 eMMC + MicroSD。永不离开设备。

2. 推理在云端执行

OpenClaw AutoAgent 在本地 ARM Cortex SoC 上执行：浏览器自动化、工具调用、自动化决策。推理不依赖云端。

3. 设备私有

用户拥有物理硬件所有权，OpenClaw 开源（BSD-3-Clause）。不依赖任何云服务持续运营。

4. 一键部署

专为 OpenClaw 设计的"一键启动"功能，用户无需复杂的命令行操作，5 分钟内跑通第一个本地自动化任务。

5. HDMI 大屏可视化

已获得 HDMI 特许任职机构专利授权，可通过 HDMI 把本地智能体状态投射到大屏。

五、PAA 五大应用场景

1. 私有智能体 — 个人 RAG + 私密助理

把个人文档 / 笔记 / 邮件索引到本地 MicroSD。OpenClaw AutoAgent 在本地执行查询和编排。所有知识库、查询历史、个人数据 全部本地。

2. 工作流自动化 — 网页任务自动执行

OpenClaw 在本地 ARM Cortex 上执行浏览器自动化：SaaS 管理 / 数据录入 / 社交媒体监控。所有账号凭据、操作日志、自动化 SOP 全部本地。

3. 行业特定方案

  • 小型 ERP 自动化 — 制造业 / 零售业的轻量 ERP 流程本地自动化
  • 智能零售助手 — 门店 POS / 库存 / 客户管理本地处理
  • 安全工业 IoT 网关 — 工厂车间数据本地采集与预处理

4. 边缘计算 — 本地实时处理

所有数据在网络边缘本地处理。降低延迟，0 云端成本。

5. HDMI 大屏数字看板

HDMI 专利输出，本地智能体实时状态投射到大屏，作为 SMB 数字员工看板。

九、结语

PAA 是私有智能体设备。用户数据本地化存储（AI 推理在云端）。

这不是营销口号 —— 这是产品设计的根本原则： - 数据本地：用户拥有完整数据所有权 - 推理在云端：用户拥有完整推理执行权 - 设备私有：用户拥有完整硬件所有权

STA-100 是 PAA 1.0 标准首款参考实现。基于当前硬件能力（4GB ARM Cortex），能完成浏览器自动化、RAG 查询、工作流编排、IoT 网关等任务。

实事求是：受硬件限制，STA-100 不是 70B 大模型推理机。后续更高规格产品待发布时再单独介绍。
