1. The Real Definition: Edge AI Agent Gateway

PAA (Personal AI Appliance) is the Edge AI Agent Gateway that STRATRONIX (Shenzhen) launched in 2026 for mid-to-senior professionals + privacy-sensitive SMBs + developers.

PAA is NOT a 1U-4U rack server. PAA is NOT an on-premise 70B LLM inference box.

It is a small ARM box that sits on your desk / in your network cabinet / at the edge node. Its three core responsibilities:

  1. Host OpenClaw + AutoAgent — Run the open-source browser automation & agent orchestration platform with one-click
  2. Bridge to Cloud LLMs — Use DeepSeek / Gemini / Claude / ChatGPT APIs as the "brain", while keeping API credentials, task logs, automation SOPs permanently local
  3. 24×7 Edge Gateway — Dual-band Wi-Fi + Gigabit Ethernet for RPA / IoT / edge computing

One-line positioning:

PAA is OpenClaw's "local brain" — Cloud LLMs do the thinking; the device keeps the memory and execution local.

4. Five Core Selling Points

4.1 One-Click Deployment — OpenClaw "One-Click Launch"

Designed for OpenClaw, the one-click launch feature lets users run agents without complex CLI. XFCE GUI means a non-technical user can deploy their first automation in under 5 minutes.

4.2 Privacy-First Architecture — Local Data Processing & SOP Storage

Your API credentials, task logs, RAG indexes, SOP workflows all live in local eMMC + MicroSD. They never leave the device — even when calling DeepSeek / Gemini / Claude / ChatGPT APIs, only the "question" goes out. The "answer + history" stays local.

4.3 Hybrid Connectivity — 5GHz Wi-Fi + Gigabit Ethernet Dual-Link

  • Dual-band 5GHz / 2.4GHz Wi-Fi: Flexible deployment, no location constraint
