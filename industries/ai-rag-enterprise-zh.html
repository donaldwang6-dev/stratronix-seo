3. 技术架构

3.1 向量数据库

  • Milvus / Qdrant — 开源向量数据库（亿级向量毫秒级检索）
  • PGVector — PostgreSQL 扩展（中小规模 RAG）
  • FAISS — Meta 开源（本地嵌入）
  • 专用嵌入模型 — BGE-M3 / mE5 / EmbeddingGemma

3.2 检索策略

  • 混合检索 — BM25（关键词）+ 向量（语义）融合
  • 重排序 — BGE-reranker / Cohere Rerank
  • 查询改写 — HyDE / Step-Back Prompting
  • 多路召回 — 文档级 / 段落级 / 表格级

3.3 LLM 推理

  • 本地模型 — Qwen2.5-72B / Llama-3.1-70B / DeepSeek-V3（量化 INT4/AWQ）

  • Prompt 工程 — 上下文压缩 + 引用追踪 + CoT 推理
