3. Technical Architecture

3.1 Vector Database

  • Milvus / Qdrant — open-source vector DB (billion-scale millisecond retrieval)
  • PGVector — PostgreSQL extension (mid-scale RAG)
  • FAISS — Meta open-source (local embedding)
  • Embedding models — BGE-M3 / mE5 / EmbeddingGemma

3.2 Retrieval Strategies

  • Hybrid retrieval — BM25 (keyword) + vector (semantic) fusion
  • Re-ranking — BGE-reranker / Cohere Rerank
  • Query rewriting — HyDE / Step-Back Prompting
  • Multi-recall — document-level / paragraph-level / table-level

3.3 LLM Inference

  • Local models — Qwen2.5-72B / Llama-3.1-70B / DeepSeek-V3 (quantized INT4/AWQ)
  • Cloud optional — OpenAI / Anthropic / DeepSeek API (with data scrubbing)
  • Prompt engineering — context compression + citation tracking + CoT reasoning
