3. STA-100 PAA 硬件配置

  • CPU：八核 ARM 架构（高通骁龙系列）
  • 内存：16 GB LPDDR5
  • 存储：256 GB NVMe SSD（可扩展至 2 TB）
  • 网络：千兆以太网 + WiFi 6 + 蓝牙 5.3
  • 电源：DC 12V 2A（Type-C PD）
  • 操作系统：OpenClaw（BSD-3 开源）
  • LLM：Qwen2.5-72B / Llama-3.1-70B（INT4 量化）或 OpenAI / Anthropic / DeepSeek API
  • 向量数据库：Milvus / Qdrant / FAISS（亿级毫秒级检索）
  • 整机功耗：≤ 35W
  • 工作温度：-10°C ~ 50°C（户外店/临时展位可行）
