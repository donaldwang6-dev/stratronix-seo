3. Specifiche STA-100 PAA

  • CPU: ARM Octa-core (serie Qualcomm Snapdragon)
  • RAM: 16 GB LPDDR5
  • Storage: 256 GB NVMe SSD (espandibile a 2 TB)
  • Rete: Ethernet Gigabit + WiFi 6 + Bluetooth 5.3
  • Alimentazione: DC 12V 2A (Type-C PD)
  • OS: OpenClaw (BSD-3 Open Source)
  • LLM: Qwen2.5-72B / Llama-3.1-70B (quantizzato INT4) o OpenAI / Anthropic / DeepSeek API
  • DB vettoriale: Milvus / Qdrant / FAISS
  • Consumo: ≤ 35 W
