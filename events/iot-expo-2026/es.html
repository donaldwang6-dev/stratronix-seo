3. Especificaciones STA-100 PAA

  • CPU: ARM Octa-core (serie Qualcomm Snapdragon)
  • RAM: 16 GB LPDDR5
  • Almacenamiento: 256 GB NVMe SSD (ampliable a 2 TB)
  • Red: Ethernet Gigabit + WiFi 6 + Bluetooth 5.3
  • Alimentación: DC 12V 2A (Type-C PD)
  • OS: OpenClaw (BSD-3 Open Source)
  • LLM: Qwen2.5-72B / Llama-3.1-70B (cuantizado INT4) o OpenAI / Anthropic / DeepSeek API
  • Base vectorial: Milvus / Qdrant / FAISS
  • Consumo: ≤ 35 W
