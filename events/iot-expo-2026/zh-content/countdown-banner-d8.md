## 📋 自动替换计划

**触发**：每日 9:00 AM（Asia/Shanghai）自动执行 cron
**逻辑**：
```bash
DAY=$(date +%-d)
MONTH=$(date +%-m)
# 8 月份
if [ "$MONTH" = "8" ]; then
  case "$DAY" in
    18) cp countdown-banner-d8.html countdown-banner-active.html ;;
    19) cp countdown-banner-d7.html countdown-banner-active.html ;;
    20) cp countdown-banner-d6.html countdown-banner-active.html ;;
    21) cp countdown-banner-d5.html countdown-banner-active.html ;;
    22) cp countdown-banner-d4.html countdown-banner-active.html ;;
    23) cp countdown-banner-d3.html countdown-banner-active.html ;;
    24) cp countdown-banner-d2.html countdown-banner-active.html ;;
    25) cp countdown-banner-d1.html countdown-banner-active.html ;;
    26|27|28) cp countdown-banner-dday.html countdown-banner-active.html ;;
  esac
fi
```
