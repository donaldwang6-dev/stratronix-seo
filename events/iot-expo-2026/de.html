3. STA-100 PAA Spezifikationen

  • CPU: ARM Octa-Core (Qualcomm Snapdragon-Serie)
  • RAM: 16 GB LPDDR5
  • Speicher: 256 GB NVMe SSD (erweiterbar auf 2 TB)
  • Netzwerk: Gigabit Ethernet + WiFi 6 + Bluetooth 5.3
  • Strom: DC 12V 2A (Type-C PD)
  • OS: OpenClaw (BSD-3 Open Source)
  • LLM: Qwen2.5-72B / Llama-3.1-70B (INT4 quantisiert) oder OpenAI / Anthropic / DeepSeek API
  • Vektor-DB: Milvus / Qdrant / FAISS
  • Leistungsaufnahme: ≤ 35 W
