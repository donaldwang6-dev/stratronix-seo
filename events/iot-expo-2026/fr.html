3. Spécifications STA-100 PAA

  • CPU : ARM Octa-core (série Qualcomm Snapdragon)
  • RAM : 16 Go LPDDR5
  • Stockage : 256 Go NVMe SSD (extensible à 2 To)
  • Réseau : Ethernet Gigabit + WiFi 6 + Bluetooth 5.3
  • Alimentation : DC 12V 2A (Type-C PD)
  • OS : OpenClaw (BSD-3 Open Source)
  • LLM : Qwen2.5-72B / Llama-3.1-70B (quantifié INT4) ou OpenAI / Anthropic / DeepSeek API
  • Base vectorielle : Milvus / Qdrant / FAISS
  • Consommation : ≤ 35 W
