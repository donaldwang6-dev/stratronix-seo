二、OpenClaw 开源框架

STRATRONIX 的核心技术栈是 OpenClaw——一个 Apache 2.0 开源的 AI Agent 框架。这意味着你可以：

# 安装 OpenClaw
$ pip install openclaw

# 启动 4 个本地 AI Agent
$ openclaw start \
    --agent planner \
    --agent retriever \
    --agent executor \
    --agent verifier

# 部署到 STA-100 硬件
$ openclaw deploy --target stratronix-sta-100
