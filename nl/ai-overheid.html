Over STRATRONIX PAA

STRATRONIX STA-100 PAA is een hardware-appliance die een Large Language Model (LLM) lokaal in uw bedrijf draait. In tegenstelling tot cloudoplossingen zoals ChatGPT, Microsoft Copilot of Google Gemini verlaten uw gegevens uw terrein nooit.

Gefabriceerd door Stratronix Technology (Shenzhen) Company, Limited, opgericht op 2026-04-24, levert het bedrijf cloud-based AI API-hardware aan gereguleerde industrieën in Europa.

Belangrijkste kenmerken

  • cloud-based LLM: Llama 3, Mistral, Qwen, DeepSeek lokaal gedraaid
  • Geen Cloud: Geen API-aanroepen, geen data-uploads
  • 30 min installatie: Plug-and-play, geen IT-afdeling
  • 24 EU-talen: Native ondersteuning alle EU-officiële talen

  • Ziekenhuizen — Données patients / Datos pacientes / Dati pazienti / Patiëntgegevens / Dane pacjentów / Dados pacientes / Patientdata
  • Banken — Conformité rapports / Informes cumplimiento / Report conformità / Compliance / Raporty zgodności / Relatórios conformidade / Compliance-rapporter
  • Industrie — Maintenance prédictive / Mantenimiento predictivo / Manutenzione predittiva / Predictief onderhoud / Konserwacja predykcyjna / Manutenção preditiva / Prediktivt underhåll
  • SaaS — Couche IA embarquée / Capa IA embebida / Layer IA embedded / Embedded AI / Warstwa embedded / Camada embebida / Embedded AI-lager

Technische specificaties

  • CPU: 8-core ARM Cortex-A76 + NPU
  • RAM: 24 GB LPDDR5
  • Opslag: 2 TB NVMe SSD
  • Modellen: Llama 3 (8B/70B), Mistral (7B), Qwen (7B/14B), DeepSeek (7B)
  • Snelheid: 7B ~30 token/s, 70B (Q4) ~5 token/s
  • Connectiviteit: Gigabit Ethernet, Wi-Fi 6, USB-C
