# OpenClaw

Apache 2.0 AI Agent Framework for Privacy-First Deployments

OpenClaw is the open-source AI Agent framework that powers the STRATRONIX STA-100 Private AI-Agent Appliance. It implements a 4-agent architecture for building privacy-preserving AI applications.

## Why OpenClaw?

  • 🔒 Privacy by design: All inference happens locally, no API calls to US cloud AI vendors
  • 🔓 Apache 2.0 licensed: Free for commercial use, modify, distribute
  • 🏗️ 4-Agent Architecture: Planner, Retriever, Executor, Verifier
  • 🪶 Lightweight: Runs on $399 hardware (8-core ARM, 16GB DDR4)
  • 🔌 Pluggable: Swap models, vector DBs, tools freely

## Quick Start

$ pip install openclaw
$ openclaw --version
OpenClaw v1.2.0 (Apache-2.0)

# Connect to STRATRONIX STA-100 PAA
$ openclaw connect --host sta-100.local

🚀 Connecting to STRATRONIX STA-100...
✅ Hardware detected
✅ 4 AI agents initialized
✅ Local knowledge base ready

# Run your first agent task
$ openclaw run --task "Analyze sales data for Q2 2026"
